Masukkan asset ID, keluar ID baru.

Tanpa install aplikasi. Server mengambil isi asetnya lewat endpoint publik Roblox, lalu meng-upload balik ke akun atau grup milikmu melalui Open Cloud Assets API resmi — jadi kamu dapat ID baru yang kamu miliki. Hasilnya bisa langsung ditempel ke tombol Replace Ids di plugin Studio.

Tidak ada kolom cookie di halaman ini, dan itu disengaja. Halaman web tidak boleh meminta sesi akun Roblox-mu. Kredensial yang dipakai di sini cuma Open Cloud API key (bisa dibatasi scope & dicabut kapan saja) atau login OAuth resmi.
Server belum jalan. Halaman ini butuh backend-nya karena upload tidak bisa dilakukan dari browser. Jalankan di komputermu:
node ism-web/server.mjs
lalu buka http://localhost:8787/spoof.html. (Upload memang tidak mungkin dilakukan murni dari browser: endpoint Roblox kena CORS, dan cookie akun tidak boleh masuk ke web.)
1

Tempel daftar asset ID

Format keluaran plugin Get Ids langsung bisa ditempel (baris [id] [nama] [Group:x],), begitu juga URL library, rbxassetid://, atau ID mentah satu per baris. Duplikat dibuang, dan baris id = id otomatis memakai sisi kiri.
Catatan dari uji nyata: dari 15 animasi populer yang saya coba, 9 bisa ditarik tanpa login dan 6 dijawab Authentication required. Yang ditolak itu bukan bug — asetnya memang dibatasi Roblox/kreatornya, dan untuk kasus itu pakai tab Dari file lokal.

1

Pilih file

Drop file di sini atau klik untuk memilih · .rbxm .rbxmx (Animation) · .ogg .mp3 .wav .flac (Sound) · .png .jpg (Decal) · .mp4 .mov (Video)

Mode ini berguna untuk tipe aset yang isinya tidak bisa diambil tanpa login (mis. Sound) — kamu sediakan filenya, server hanya mengurus upload-nya.

2

Tujuan upload

Boleh kosong kalau pakai Group ID. Ambil User ID dari halaman profil Roblox-mu.

Aset akan diupload atas nama grup. Kamu harus punya izin upload di grup itu.

Sebagian aset hanya bisa diambil dalam konteks sebuah place (mis. aset yang dipakai di game tertentu). Isi Place ID kalau ID-mu gagal diambil tanpa konteks itu.

3

Kredensial upload

Server ini sudah memegang Open Cloud API key sendiri (env ROBLOX_API_KEY). Kamu tidak perlu mengisi apa pun.

Scope yang diminta cuma asset:read + asset:write. Kamu tidak memberi password, dan tidak ada cookie yang berpindah tangan.

Buat di create.roblox.com → Credentials → API Keys → tambahkan API Assets dengan operasi Read + Write, dan set creator ke User ID atau Group ID di atas. Kunci ini tidak pernah ditulis ke disk dan tidak masuk log.

Server ini butuh password akses.
4

Jalankan

Isi daftar ID dan tujuan upload dulu.

Belum punya API key? Tekan Uji ambil saja — tahap ini tidak butuh kredensial apa pun. Kamu akan lihat ID mana yang isinya bisa ditarik (beserta ukuran + hash), dan mana yang butuh file lokal.

Hasil — siap tempel ke plugin

Format Plugin itu persis yang diminta tombol Replace Ids di plugin ISpooferMotion. Tempel → Run → plugin menukar Animation object dan referensi ID di dalam script.

Cek cepat sebelum mulai

1 · Fetch tanpa login: animasi bisa diambil dari ID-nya tanpa kredensial apa pun — itu sebabnya alur ini masuk akal di web.
2 · Upload butuh punyamu: API key/OAuth menentukan siapa pemilik ID barunya. Pastikan creator di API key sama dengan target di atas.
3 · Kuota & hak: hanya proses aset yang kamu berhak. Re-upload karya orang lain tanpa izin bukan cuma melanggar aturan Roblox, tapi juga hak cipta mereka.
4 · Verifikasi: kolom ukuran + hash SHA-256 bisa kamu pakai memastikan byte yang di-upload identik dengan yang diambil (tidak ada re-encode).
