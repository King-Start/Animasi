Web Spoofer: masukkan ID, keluar ID baru

Alur inti ISpooferMotion yang dulu hanya ada di app desktop sekarang bisa dijalankan dari browser. Tempel daftar asset ID → server mengambil isinya → upload balik ke akun atau grup milikmu lewat Open Cloud Assets API resmi Roblox → hasilnya siap ditempel ke plugin Studio.

WEB

1 · Ambil isi aset

Endpoint delivery Roblox ternyata mengembalikan isi aset tanpa perlu login sama sekali — termasuk animasi. Jadi langkah ini tidak menyentuh kredensial apa pun: server cuma minta lokasi CDN, mengunduh bytenya, dan mencatat hash-nya.

WEB

2 · Upload atas namamu

Upload memakai API resmi Roblox dengan Open Cloud API key (scope asset:write) atau login OAuth 2.0. Tidak ada cookie akun yang diminta, disimpan, atau diteruskan — dan itu bisa dibuktikan di source-nya.

WEB

3 · Tempel ke plugin

Hasilnya keluar dalam format yang persis diminta tombol Replace Ids — id_lama = id_baru, satu per baris. Tempel, Run, dan plugin menukar Animation object serta referensi ID di dalam script.

Batasan yang jujur

• Butuh server kecil. Upload mustahil dilakukan murni dari browser: endpoint Roblox kena CORS, dan cookie akun tidak boleh masuk ke web. Jadi server Node-nya jalan di komputermu sendiri — satu perintah, tanpa install aplikasi desktop.

• Audio (Sound) masih butuh file lokal. Isi audio di balik otentikasi, jadi untuk sound pakai mode dari file lokal: kamu sediakan filenya, server mengurus upload-nya.

• Bukan semua ID publik. Saat saya uji 15 animasi populer, 9 bisa ditarik tanpa login dan 6 ditolak. Yang ditolak harus kamu sediakan sendiri filenya.

• Tetap sama aturannya: hanya proses aset yang kamu punya hak atau izinnya.

Cara menjalankan

terminalnode 20+
# jalankan server + situs dari satu perintah
node ism-web/server.mjs

# lalu buka
http://localhost:8787/spoof.html

Butuh Open Cloud API key dengan API Assets (operasi Read + Write) — dibuat di create.roblox.com → Credentials → API Keys. Atau daftarkan OAuth 2.0 app dengan scope asset:read asset:write dan login lewat tombol di halaman spoofer.

Kunci API-nya tidak pernah ditulis ke disk dan tidak pernah masuk log. Kalau kamu memakai kunci server (ROBLOX_API_KEY), user yang membuka halaman bahkan tidak perlu mengisi apa pun.

Cara Kerja

Empat langkah dari ID lama ke ID baru

Alur ini yang dipakai versi desktop. Semua langkah di bawah dijalankan di komputer kamu sendiri — app yang memegang sesinya, bukan server pihak ketiga.

01

Kumpulkan asset ID

Buka place di Roblox Studio, tekan tombol Get Ids di plugin ISpooferMotion, lalu copy seluruh isi textbox-nya. Bisa juga tempel ID secara manual kalau kamu sudah tahu targetnya.

02

Tempel ke app & pilih akun

Paste daftar ID ke textbox di app, pilih profile akun (atau Group ID) yang mau dipakai sebagai tujuan upload. Di V2 kredensial per profile dipegang oleh credential store OS.

03

Fetch → re-upload, satu pipeline

App mengambil tiap aset memakai sesi milikmu, lalu meng-upload balik ke akun/grup tersebut sehingga kamu mendapat asset ID baru yang dimiliki profile itu. Kamu tidak perlu menyimpan file-nya ke disk lebih dulu. Web Spoofer melakukan dua langkah ini juga, tapi lewat Open Cloud API key/OAuth — tanpa app desktop dan tanpa sesi akun.

04

Replace di Studio

Copy output-nya, kembali ke Studio, tekan Replace Ids di plugin, tempel, lalu Run. Plugin mengganti Animation object dan ID yang tertulis di dalam script — termasuk referensi yang tersembunyi di dalam kode.

Format yang dibaca

.rbxmx / .rbxm / .xml berisi Item class="KeyframeSequence", dengan Pose bertingkat maupun datar, dan rotasi modern CFrame (R00…R22) atau format lama EulerRotation. File .rbx biner tidak didukung — simpan ulang sebagai XML dari Studio.

Interpolasi standar

Posisi diinterpolasi linear, rotasi pakai slerp antar keyframe — sama seperti cara engine memutar animasi. Joint yang tidak dipose di sebuah keyframe otomatis memakai nilai keyframe sebelumnya.

FAQ

Pertanyaan yang sering muncul

Apa bedanya V1 dan V2?
V1 (ISpooferMotion) adalah animation spoofer/re-uploader klasik berbasis Electron: tempel ID → upload → replace lewat plugin Studio. Rilisan terakhirnya v1.3.20.

V2 (ISpooferMotion-V2) ditulis ulang dengan Tauri 2 + Rust + React 19 + Luau. Cakupannya lebih luas — bukan cuma animasi, tapi juga sound, decal, mesh, dan video; ditambah preview R6/R15, profiles per user/grup, dan place browser untuk menelusuri asset tree. Kalau kamu mulai dari nol sekarang, ambil V2.
Kenapa butuh akun Roblox / kredensial?
Upload asset hanya bisa dilakukan atas nama akun yang punya izin, jadi selalu ada kredensial yang terlibat — tapi bentuknya beda:

• Web Spoofer memakai Open Cloud API key (scope asset:read/asset:write) atau login OAuth 2.0. API key bisa dibatasi hanya ke operasi Assets, dicabut kapan saja, dan bahkan diberi batas IP. Tidak ada cookie akun sama sekali.

• App desktop V1/V2 memakai sesi login milikmu — V1 lewat deteksi sesi otomatis atau input manual, V2 lewat profiles dengan credential store milik OS. Di situ sesi dipegang komputer kamu sendiri, bukan server orang lain.
Apakah aman menempelkan cookie / sesi login?
Sesi login Roblox setara kunci penuh akunmu: siapa pun yang memegangnya bisa masuk tanpa password dan tanpa 2FA. Karena itu aturannya sederhana:

1. Pakai akun alt/burner untuk eksperimen, bukan akun utama.
2. Hanya masukkan sesi ke app desktop resmi yang kamu jalankan sendiri di komputer kamu.
3. Jangan pernah menempelkan cookie Roblox ke website, form, atau "tool online" apa pun — termasuk halaman ini. Situs ini memang sengaja tidak punya kolom login sama sekali: playground di atas cuma membaca file lokal di browser kamu.
Bisa dipakai langsung dari browser / HP?
Ya, untuk animasi. Web Spoofer menjalankan alur lengkap: isi daftar ID → ambil isi aset → upload balik → keluarkan id_lama = id_baru, siap tempel ke plugin Studio. Bedanya dengan app desktop cuma satu: butuh server Node kecil yang kamu jalankan sendiri (satu perintah), karena endpoint upload Roblox kena CORS dan cookie akun tidak boleh lewat web.

Jadi dari HP pun bisa, asal servernya jalan di suatu tempat yang bisa kamu akses. Yang tetap perlu app desktop: hal-hal yang menyentuh place secara langsung (scan seluruh place, preview R6/R15 di dalam Studio, place browser V2).
Windows Defender / antivirus saya menandai build-nya. Kenapa?
Rilis ISpooferMotion belum di-code signing, dan build aplikasi yang menyentuh kredensial memang sering kena deteksi heuristik. Ini disebutkan sendiri di README resmi V2. Kalau kamu tidak nyaman dengan build bawaan, kamu bisa compile sendiri dari source (bun install lalu bun run tauri:dev) dan memverifikasi kodenya.

Kalau kamu memang ingin menghindari installer sama sekali, Web Spoofer adalah jalur yang lebih ringan: tidak ada binary, tidak ada installer, dan kamu bisa membaca sendiri kode servernya sebelum menjalankannya.
Apakah ini melanggar aturan Roblox / bisa kena ban?
Otomasi upload memakai sesi akun adalah area abu-abu, dan tanggung jawab pemakaian ada di kamu. Yang jelasnya begini: hanya re-upload aset yang kamu punya hak atau izinnya — misalnya animasi buatanmu sendiri, aset tim/studi kamu, atau aset yang pemiliknya sudah memberi izin. Mengambil aset milik kreator lain tanpa izin bukan cuma melanggar aturan platform, tapi juga hak cipta mereka. Gunakan akun alt dan pahami risikonya.
Bagaimana cara berkontribusi atau lapor bug?
Project ini GPL-3.0-or-later dan terbuka untuk PR. Baca .github/CONTRIBUTING.md, branch dari main, pakai Conventional Commits, dan pastikan bun run check lolos sebelum push. Bug dan permintaan fitur lewat tab Issues di repo V2.

Baca ini sebelum menjalankan

  1. Sesi login = kunci penuh akun. Simpan hanya di app desktop yang kamu jalankan sendiri, dan latih dulu dengan akun alt. Tidak ada tool online tepercaya untuk hal ini — kalau ada situs yang meminta cookie Roblox-mu, itu polanya sama dengan phishing. Web Spoofer tidak butuh cookie sama sekali, jadi kalau ada "situs spoofer" yang memintanya, jangan.
  2. Hanya proses aset yang kamu berhak. Re-upload karya orang lain tanpa izin = pelanggaran aturan platform sekaligus hak cipta.
  3. Verifikasi build. Rilis belum code-signed, jadi antivirus bisa memberi false positive. Sumber lengkapnya ada di GitHub kalau kamu ingin membangun sendiri.
  4. Untuk jalur web: pakai API key yang dibatasi operasinya (hanya Assets), pasang batas IP kalau bisa, dan jangan pakai kunci yang sama dengan proyek lain. Kalau kamu memakai OAuth, scope-nya cuma asset:read asset:write dan bisa dicabut dari akun Roblox-mu kapan saja.
